


# Troubleshooting Static Routes

## Overview

This lab focuses on identifying and resolving common problems affecting static routing and network connectivity.

## Objectives

* Identify routing errors
* Check interface configuration
* Verify IP addressing
* Analyze routing tables
* Test and restore connectivity

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Identified routing and configuration issues and restored communication between networks.
